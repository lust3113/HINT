# 승인 위임 앱 초보자 가이드

코드를 붙여넣고, 배포하고, 휴대폰에서 열어 보기까지 순서대로 따라 하는 문서입니다.
가상 데이터로 실험하는 앱이라 보안 설정은 단순하게 잡았습니다. 실제 업무 자료는 넣지 마세요.

> 구글 화면의 메뉴 이름은 업데이트로 조금 달라질 수 있어요. 아래 글씨와 똑같지 않으면 비슷한 이름을 찾으세요.

## 이 앱이 하는 일

신청서(제목, 신청자, 금액, 내용, 중요도)를 제출하면 규칙에 따라 판정합니다. AI API는 쓰지 않고 숫자와 키워드만 봅니다.

| 판정 | 조건 |
|---|---|
| 반려 | 제목이나 내용에 **금지 키워드**가 있을 때 |
| 보류 | 금액이 **한도를 넘을 때**, 필수 항목이 **비었을 때**, **주의 키워드**가 있을 때 |
| 승인 | 위에 해당하지 않을 때 |

처리 방식은 이렇습니다.

| 판정 | 중요도 | 처리 |
|---|---|---|
| 승인 | 하 | 자동 승인, 기록만 남김 |
| 승인 | 상, 중 | 승인이어도 관리자에게 이메일 전송 |
| 보류, 반려 | 모두 | 관리자에게 이메일 전송 |

여러 조건이 동시에 걸리면 **반려 > 보류 > 승인** 순서로 정해집니다. 금액이 한도를 넘으면 중요도를 "하"로 골라도 보류됩니다.

## 준비물

- 구글 계정 (Gmail)
- 이 폴더의 파일 두 개: `Code.gs`, `index.html`

---

## 1단계. 스프레드시트 만들기

1. 브라우저에서 [sheets.google.com](https://sheets.google.com)에 들어가 **빈 스프레드시트**를 만듭니다.
2. 왼쪽 위 파일 이름을 `승인앱`처럼 알아보기 쉽게 바꿉니다.

## 2단계. Apps Script 열기

1. 스프레드시트 위쪽 메뉴에서 **확장 프로그램 → Apps Script**를 누릅니다.
2. 새 탭에 코드 편집기가 열립니다. 이 스프레드시트에 붙은 스크립트라서, 시트를 코드에 따로 연결할 필요가 없습니다.

## 3단계. Code.gs 붙여넣기

1. 편집기 왼쪽 파일 목록에 `Code.gs`가 있습니다. 눌러서 엽니다.
2. 안에 있는 내용(`function myFunction() {...}`)을 **전부 지웁니다**. (Ctrl+A 후 Delete)
3. 이 폴더의 `Code.gs` 내용을 **전부 복사해서 붙여넣습니다**.
4. 위쪽의 저장 아이콘(디스크 모양)을 누르거나 Ctrl+S를 누릅니다.

## 4단계. index.html 만들고 붙여넣기

1. 파일 목록 위의 **+** 버튼을 누르고 **HTML**을 고릅니다.
2. 이름을 **`index`** 라고 입력하고 Enter를 누릅니다. (소문자, `.html`은 자동으로 붙습니다)
3. 안에 미리 들어 있는 내용을 **전부 지웁니다**.
4. 이 폴더의 `index.html` 내용을 **전부 복사해서 붙여넣고 저장**합니다.

이름이 `index`가 아니면 화면이 열리지 않으니 꼭 확인하세요.

## 5단계. 처음 한 번 setup 실행하기 (권한 승인)

1. 편집기 위쪽에서 실행할 함수를 고르는 칸을 눌러 **`setup`**을 고릅니다.
2. **실행** 버튼을 누릅니다.
3. "승인이 필요합니다" 창이 뜨면 **권한 검토**를 누르고 본인 구글 계정을 고릅니다.
4. "Google에서 확인하지 않은 앱입니다" 화면이 나오면 정상입니다. 내가 직접 만든 스크립트라 그렇습니다.
   - **고급**을 누르고 맨 아래 **(프로젝트 이름)(안전하지 않음)으로 이동**을 누릅니다.
   - 요청 권한(스프레드시트, 이메일 발송 등)을 읽어 보고 **허용**을 누릅니다.
5. 아래 실행 로그에 "설정 완료"가 나오면 성공입니다.
6. 스프레드시트 탭으로 돌아가 보면 **`설정`**, **`처리기록`** 시트가 생겨 있습니다.

## 6단계. 설정 시트에서 기준 고치기

`설정` 시트의 **B열(값)** 만 고치면 됩니다. 코드는 건드리지 않아도 됩니다.

| 이름 | 설명 | 기본값 |
|---|---|---|
| 금액한도 | 이 금액을 넘으면 보류 (숫자만) | 1000000 |
| 관리자이메일 | 알림 받을 주소. 비우면 내 구글 계정으로 옵니다 | (비어 있음) |
| 금지키워드 | 포함되면 반려. 쉼표로 구분 | 도박,불법,뇌물,리베이트 |
| 주의키워드 | 포함되면 보류. 쉼표로 구분 | 긴급,선지급,현금,외부 송금 |

키워드는 띄어쓰기가 달라도 찾아냅니다. (예: "외부송금"과 "외부 송금" 모두 걸립니다.)
설정은 신청이 들어올 때마다 새로 읽기 때문에 **다시 배포하지 않아도** 바로 적용됩니다.

## 7단계. 웹앱으로 배포하기

1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴(유형 선택)를 누르고 **웹 앱**을 고릅니다.
3. 아래처럼 설정합니다.
   - 설명: `v1` (아무 말이나 괜찮습니다)
   - **다음 사용자로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자** (실험용입니다. 링크를 아는 사람은 누구나 접속합니다)
4. **배포**를 누릅니다.
5. 나오는 **웹 앱 URL**을 복사해 둡니다. 이 주소가 앱 주소입니다.

## 8단계. 휴대폰에서 열기

1. 복사한 URL을 휴대폰으로 보냅니다. (카카오톡 나에게 보내기, 메일 등)
2. 휴대폰 브라우저에서 URL을 엽니다.
3. 자주 쓰려면 홈 화면에 추가하세요.
   - 아이폰(Safari): 공유 버튼 → **홈 화면에 추가**
   - 안드로이드(Chrome): 메뉴(점 세 개) → **홈 화면에 추가**

## 9단계. 동작 확인하기

아래 예시를 하나씩 제출해 보세요. (기본 설정 기준)

| # | 제목 | 금액 | 내용 | 중요도 | 기대 결과 |
|---|---|---|---|---|---|
| 1 | 사무용품 구매 | 50000 | 볼펜과 노트 구매 | 하 | 승인, 자동 승인 완료 (메일 없음) |
| 2 | 노트북 구매 | 800000 | 신입 사원용 노트북 | 중 | 승인, 관리자 확인 대기 (메일 옴) |
| 3 | 장비 구매 | 3000000 | 서버 장비 교체 | 하 | 보류, 금액 한도 초과 (메일 옴) |
| 4 | 출장 선지급 | 200000 | 긴급 출장비 요청 | 하 | 보류, 주의 키워드 (메일 옴) |
| 5 | 행사 경비 | 100000 | 도박 이벤트 상품 구입 | 하 | 반려, 금지 키워드 (메일 옴) |
| 6 | (제목 비움) | 10000 | 내용 있음 | 하 | 보류, 필수 항목 누락 (메일 옴) |

제출할 때마다 `처리기록` 시트에 한 줄씩 쌓입니다.

## 코드를 고쳤을 때 (중요)

`Code.gs`나 `index.html`을 수정하면 **새 버전으로 다시 배포**해야 휴대폰에 반영됩니다.

1. **배포 → 배포 관리**를 누릅니다.
2. 연필(편집) 아이콘을 누릅니다.
3. 버전을 **새 버전**으로 바꿉니다.
4. **배포**를 누릅니다. 웹 앱 URL은 그대로입니다.

설정 시트의 값(한도, 키워드, 이메일)을 바꿀 때는 다시 배포할 필요가 없습니다.

## 문제가 생겼을 때

| 증상 | 확인할 것 |
|---|---|
| 화면이 안 열리고 오류가 난다 | 4단계의 HTML 파일 이름이 정확히 `index`인지 확인 |
| "스크립트 함수를 찾을 수 없음" | 3단계에서 `Code.gs`의 내용을 빠짐없이 붙여넣었는지 확인 |
| 이메일이 안 온다 | 스팸함 확인. 5단계 권한 승인을 했는지 확인. 개인 계정은 하루 약 100통 제한 |
| 휴대폰에서 로그인하라고 나온다 | 7단계의 "액세스 권한"이 **모든 사용자**인지 확인 |
| 수정했는데 그대로다 | "코드를 고쳤을 때" 순서대로 **새 버전**으로 다시 배포 |
| 키워드가 안 걸린다 | `설정` 시트의 쉼표 구분, 오타 확인 |
| `처리기록` 시트가 없다 | 5단계의 `setup`을 실행하면 다시 만들어집니다 |

## 파일 구성

- `Code.gs`: 판정 규칙, 시트 기록, 이메일 알림 (백엔드)
- `index.html`: 휴대폰용 신청 화면 (화면)
- `GUIDE.md`: 이 문서
